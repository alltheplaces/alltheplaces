# Finland

Address data for Finland is provided by Ryhti, the built environment information system,
through the Finnish Environment Institute (Syke).

## Data Sources

Dataset documentation: https://ckan.ymparisto.fi/dataset/rakennetun-ympariston-tietojarjestelman-rakennusten-osoitetiedot

- **OGC API Features**: https://paikkatiedot.ymparisto.fi/geoserver/ryhti_building/ogc/features/v1/collections/open_address/items
